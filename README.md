# 🛡️ CyberShield — Premium Edition

**URL Threat Intelligence Dashboard**

CyberShield is a professional-style cybersecurity web application that analyzes URLs for common phishing and suspicious-link indicators and produces an explainable risk score.

- Explainable risk score (0–100)

- Suspicious keyword analysis
- Long URL detection
- Subdomain analysis
- Security signal report
- Portfolio-ready README

## 🧰 Technology

- Python
- Streamlit
- URL parsing
- Regular expressions
- HTML/CSS UI customization

## ▶️ Run on Windows

1. Install Python 3.11+.
2. Extract this ZIP.
3. Open the `CyberShield_Premium` folder.
4. Double-click `run_windows.bat`.
5. The application will open in your browser.

Or use Terminal:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ⚠️ Security note

This version uses explainable heuristics. It is **not** a production malware/phishing verdict engine. Real-world security products typically combine reputation services, threat intelligence, machine learning, DNS/domain intelligence, sandboxing, browser telemetry and other controls.
